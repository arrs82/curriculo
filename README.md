## 🧩 Sobre o projeto

Este repositório contém o código-fonte do meu **currículo profissional e site pessoal**, desenvolvido com o gerador estático **MkDocs** e o tema **Material for MkDocs**.  
O objetivo é apresentar minha trajetória profissional, formações, experiências e projetos de forma moderna, visual e responsiva.

---

## ⚙️ Tecnologias utilizadas
- **MkDocs** e **Material for MkDocs**
- **Markdown (.md)**  
- **HTML, CSS e JavaScript**
- **GitHub Pages** (deploy automático via branch `gh-pages`)
